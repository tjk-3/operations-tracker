# Operations Tracker

A Python and SQLite tool for tracking projects, deadlines, ownership, and next actions across active workflows.

## Purpose

This tool is being built to organize real operational work and improve visibility into:

- Overdue items  
- Upcoming deadlines  
- Project ownership  
- Next required actions  
- Stalled or missing tasks  

Work is often scattered across emails, notes, conversations, and spreadsheets.  
This project creates a single system to track and manage active projects in one place.
